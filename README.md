# PAI最終課題

## 概要

本課題では、生成AI（Gemini 3.5 Flash）とロボットシミュレーション（PyBullet）を組み合わせ、R2D2が障害物を回避しながらゴール地点へ移動するデモシステムを作成しました。

ユーザーから与えられた自然言語による指示を基に、シミュレーション空間内にロボット、障害物、ゴールを配置し、移動の様子を動画として出力します。
---
# システム構成
-Gemini 3.5 Flash
  ユーザー指示の解釈
  目的地情報の取得

-Python
  ロボット制御
  動画生成
  経路管理

-PyBullet
  ロボットシミュレーション

-ImageIO
 MP4動画出力
---
# 実装内容

# シミュレーション環境
-R2D2ロボット
-赤色の障害物
-緑色のゴール地点
を配置し、ロボットが障害物を回避しながらゴールへ向かう環境を構築しました。

# 動画の流れ
1.オープニング
2.障害物回避デモ
3.ゴール到達
4.エンディング

# 障害物回避
障害物を一直線上に配置し、ロボットがジグザグに移動することで各障害物を回避するよう設計しました。
---
工夫した点
1. 生成AIとの連携
Gemini APIを利用し、自然言語による指示とロボットシミュレーションを連携させました。

2. 可視化
-障害物：赤色
-ゴール：緑色
-現在位置
-ゴールまでの残距離
を表示し、ロボットの状態が分かりやすいよう工夫しました。

3. ロボットの移動改善
ロボットが急旋回しないよう進行方向を徐々に変更することで、実際の移動体に近い挙動を再現しました。

4. 動画演出
オープニング・ゴール到達画面・エンディングを追加し、単なるシミュレーション結果ではなくデモ動画として見やすい構成としました。
